# Chapter 1: Python Fundamentals

This chapter builds the Python foundation needed for bioinformatics and computational biology. The emphasis is not on learning Python in isolation, but on using Python to manipulate biological information such as DNA sequences, RNA sequences, amino-acid strings, sample metadata, and simple experimental measurements.

## Learning Goals

By the end of this chapter, you should be able to:

- Write and run basic Python programs.
- Store biological information in appropriate data types.
- Manipulate DNA, RNA, and protein sequences as strings.
- Use lists, tuples, dictionaries, and sets to organize biological data.
- Make decisions with `if`, `elif`, and `else`.
- Process sequences and datasets with `for` and `while` loops.
- Write reusable functions for biological calculations.
- Read from and write to text files.
- Handle common runtime errors safely.
- Understand basic object-oriented programming well enough to use biological Python libraries later.

## Recommended Workflow

For every section:

1. Read the lesson.
2. Type the examples yourself rather than only copying them.
3. Change the biological inputs and predict the output.
4. Complete the exercises without looking at solutions.
5. Keep small experiments in your own Python notebook or `.py` files.

## Prerequisites

No prior Python programming experience is assumed. Basic familiarity with DNA, RNA, proteins, and common biological measurements is helpful.
